# EINX Project

## Installation 

```bash
pip install einx

pip install einops

pip install einmesh

pip install numpy
```

Alternatively you can use this to get all required packages:

```bash
pip install -r src/requirements.txt
```

## Requirements 

python version of 3.10+ should be compatible with both einx and einops
